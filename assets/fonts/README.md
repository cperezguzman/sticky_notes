# Bundled fonts

Body typography for the SDL GUI. **Debug 8×8** (SDL debug bitmap) remains the default and does not use these files.

| UI name | File(s) | License / notes |
|---------|---------|-----------------|
| **Sans** | `DejaVuSans*.ttf` (+ Bold / Oblique) | DejaVu (Bitstream Vera / Arev) |
| **Serif** | `DejaVuSerif*.ttf` (+ Bold / Italic) | DejaVu |
| **Mono** | `DejaVuSansMono*.ttf` (+ Bold / Oblique) | DejaVu |
| **Times** | `LiberationSerif-*.ttf` | Liberation Fonts — Times New Roman–compatible metrics (not Microsoft TNR) |
| **Papyrus** | `IMFellEnglish-*.ttf` | OFL — IM Fell English (papyrus-like substitute; not proprietary Papyrus) |
| **Art Deco** | `Limelight-Regular.ttf` | OFL — Limelight by Sorkin Type |

Bold/italic use real face files when present; underline and strikethrough are drawn as lines.
